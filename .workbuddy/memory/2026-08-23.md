## 完成工作

用 PyQt6 完全重构了 DTUG-IDE，从 Flask Web UI 迁移为纯桌面客户端。

### 新增/修改文件

- `dtug_ide/__init__.py`
- `dtug_ide/__main__.py` — 入口点
- `dtug_ide/main_window.py` — 主窗口（多标签、工具栏、控制台、评测面板）
- `dtug_ide/editor.py` — C++ 语法高亮编辑器（含行号、自动缩进、括号补全）
- `dtug_ide/compiler.py` — 编译与运行核心（线程读取避免 pipe 死锁）
- `dtug_ide/judge.py` — OJ 风格沙盒评测引擎
- `dtug_ide/utils.py` — 工具函数
- `requirements.txt`
- `README.md`

### 修复的 Bug（对应 bug_report.md）

| 编号 | 问题 | 修复方式 |
|------|------|----------|
| 1 | pipe 死锁导致正确程序 TLE | 使用独立线程读取 stdout/stderr |
| 2 | 编译器选择器无效 | PyQt6 QComboBox 实际传入编译命令 |
| 3 | 超时后残留进程未 kill | `kill_process_tree` 强制结束子进程 |
| 4 | 预热进程未 wait | 正常分支也调用 wait |
| 5 | stderr 混入 stdout 比对 | 严格分离 stdout/stderr，仅 stdout 参与比对 |
| 6 | Windows 编码问题 | `decode("utf-8", errors="replace")` |
| 7 | 路径含空格导致 CMD 启动失败 | 使用列表传参，避免 shell=True |
| 8 | 临时文件残留 | 进程结束后再清理，独立目录运行 |
| 9 | 无沙箱隔离 | 每个测试点 `tempfile.mkdtemp` 独立目录 |
| 10 | 前端 XSS 风险 | 无 Web UI，天然免疫 |
| 11 | time_limit / memory_limit 未校验 | 限制在 [0.1, 60] 和 [1, 4096] |
| 12 | 无扩展名文件名解析错误 | 跳过隐藏文件，使用 rsplit |
| 13 | 测试用例排序混乱 | 自然排序（数字感知） |
| 14 | 悬空 DOM 引用 | 无 Web UI |
| 15 | 编译错误不展示编译日志 | 评测时编译错误输出到控制台 |
| 16 | 启动清理不彻底 | `clean_temp_dir` 递归清理 |
| 17 | 测试点之间文件状态共享 | 每个测试点独立工作目录 |
| 18 | 非 0 退出码时 pause 不执行 | `& pause` 替代 `&& pause` |
